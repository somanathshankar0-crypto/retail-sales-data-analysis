# Retail Sales Data Analysis

## 📌 About the Project

This project explores a retail sales dataset using Python and data analysis libraries. The goal is to understand sales trends, customer purchasing patterns, product category performance, and differences in spending across customer groups.

This is my first retail data analysis project, where I applied the concepts I learned in Python, Pandas, and data visualization.

## 🎯 Objectives

- Analyze total sales across product categories.
- Compare purchasing patterns by gender.
- Explore monthly sales trends.
- Study spending patterns across different age groups.
- Analyze sales by weekday and quantity purchased.
- Visualize relationships and patterns using charts and heatmaps.

## 📊 Dataset

- **Source:** [Retail Sales Dataset — Kaggle](https://www.kaggle.com/datasets/mohammadtalib786/retail-sales-dataset)
- **Records:** 1,000 transactions
- **Features:** 9 original columns

The dataset includes information such as date, gender, age, product category, quantity, price per unit, total amount, and transaction details.

## 🛠️ Tools and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Visual Studio Code

## 🔍 Analysis Performed

- Data inspection and cleaning checks
- Missing value and duplicate checks
- Sales aggregation using `groupby()`
- Summary statistics and category comparisons
- Pivot tables using `pivot_table()`
- Date-based and monthly analysis
- Age-group analysis
- Data visualization using bar plots, box plots, strip plots, swarm plots, regression plots, joint plots, and heatmaps

## 📈 Key Findings

Based on my analysis of the dataset:

- Electronics generated the highest total sales among the product categories.
- Beauty generated the lowest total sales among the product categories.
- Female customers accounted for 510 transactions, compared with 490 transactions from male customers.
- Female customers had higher total sales and a higher average transaction amount in this dataset.
- May recorded the highest total sales and transaction count.
- February recorded the highest average transaction amount.
- The 46–55 age group generated the highest total spending.
- The 18–25 age group had the highest average transaction amount.
- Female customers had the highest average transaction amount in Clothing, while male customers had theirs in Beauty.
